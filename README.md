# 🌐 Projeto WEB — Agenda 16 | estudo Desenvolvimento de Sistemas modulo I

Projeto desenvolvido para a disciplina Desenvolvimento de Sistemas I com o objetivo de criar uma página WEB interativa utilizando HTML, CSS, JavaScript e o framework W3.CSS.

O site foi elaborado com foco em design moderno, organização visual e experiência do usuário, apresentando uma estrutura completa de empresa fictícia com navegação dinâmica e slideshow de produtos/serviços.

## ✨ Funcionalidades do Projeto

* Sidebar interativa para navegação;
* Seção Serviços / Produtos com slideshow;
* Slideshow manual e automático utilizando JavaScript;
* Cabeçalho personalizado com logotipo e slogan;
* Layout responsivo utilizando W3.CSS;
* Rodapé com redes sociais e contato comercial;
* Estrutura organizada e estilização moderna.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* W3.CSS

## 📚 Competências Desenvolvidas

* Implementação de páginas para Internet;
* Utilização de linguagem de script para WEB;
* Organização estrutural de interfaces;
* Criação de elementos interativos;
* Aplicação de boas práticas em desenvolvimento WEB.

## 🤖 Inteligência Artificial como Apoio Técnico

A IA foi utilizada como suporte técnico durante o desenvolvimento do projeto para:

* auxiliar na implementação do slideshow;
* sugerir melhorias visuais e estilização;
* identificar possíveis erros de codificação;
* otimizar a organização da página.

## 🚀 Resultado Final

O projeto resultou em uma interface moderna, funcional e responsiva, demonstrando evolução prática no desenvolvimento front-end e na criação de experiências visuais para WEB.
